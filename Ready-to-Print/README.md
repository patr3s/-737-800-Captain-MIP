# Ready-to-Print

Tento priečinok obsahuje iba skontrolované výrobné exporty pre 5s3a.

Carrier v1 sem bude presunutý po úspešnom STL exporte, kontrole geometrie a potvrdení rastra montážnych otvorov voči DU bezel v2.

## Uvoľnené diely

- `737-MIP-CAL-001_M3-calibration-coupon_v1.stl` – vytlačiť 1 ks ako prvý diel projektu.
- `POKYNY_PRE_5s3a.md` – kompletné nastavenie tlače a postup vyhodnotenia testu.
- `Backlight-Test-v1/` – prvý trojvrstvový test podsvietenia; 3 STL a samostatný tlačový návod.
- `VYSLEDOK_5s3a.md` – výsledok CAL-001; M3 priechodzí otvor 3,2 mm potvrdený pre sivý Anycubic PETG, flow 0,96.
